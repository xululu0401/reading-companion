阅读搭子｜Mac 提示“无法验证”时如何打开
适用于 0.3.2 · macOS 13 及以上 · M 系列芯片（含 M5）

如果你看到下面这类提示，请阅读本说明：
“未打开‘阅读搭子’。Apple 无法验证‘阅读搭子’是否包含可能危害 Mac 安全或泄漏隐私的恶意软件。”

一、为什么会出现这个提示？

当前版本尚未完成 Apple Developer ID 签名与公证，所以 macOS 不能通过 Apple 的分发认证来验证应用。
0.3.2 已修复旧版安装包的签名完整性问题，但使用的是本地（ad-hoc）签名，不能替代 Apple 公证。
这条“无法验证”提示不等于系统已经检出了恶意软件，也不构成软件安全保证。

二、确认来源后，如何单独允许这个应用？

请先确认安装包来自阅读搭子的官方 GitHub 发布页，或开发者本人提供的网盘分享。
如果你不确定文件来源，先不要允许打开。

1. 在弹窗中点击“完成”。不要点击“移到废纸篓”。
2. 确认“阅读搭子.app”已放入 Mac 的“应用程序”文件夹。
3. 打开左上角苹果菜单 →“系统设置”。
4. 进入“隐私与安全”，向下滚动，找到“安全性”区域。
5. 找到与“阅读搭子”有关的阻止提示，点击“仍要打开”。不同系统版本的措辞可能略有不同。
6. 按系统要求输入管理员密码或使用 Touch ID。
7. 如果系统再次询问，阅读提示后确认“仍要打开”或“打开”。

这是你针对这一个应用作出的允许决定，不需要关闭 Mac 的整体安全保护。
后续通常可以从“应用程序”或 Dock 打开；重新下载或升级后，系统可能再次询问。

三、没有“仍要打开”，怎么办？

• 先从“应用程序”再次尝试打开阅读搭子，关闭提示后重新查看“隐私与安全”。
• 确认已经解压安装包，操作的是“阅读搭子.app”，而不是 ZIP 文件。
• 确认使用的是 0.3.2 或后续版本。0.3.1 旧包曾存在签名完整性问题，不建议继续使用。
• 如果电脑由公司或学校管理，相关操作可能被限制，请联系设备管理员。
• 仍然没有对应按钮时，请反馈完整弹窗、系统版本及芯片型号；不要为了打开应用而关闭全局安全保护。

四、如果仍提示“已损坏，无法打开”

“已损坏”与本说明开头的“Apple 无法验证”不是同一条提示，处理时需要区分。

1. 重新下载最新安装包。已有笔记时先备份，退出旧版后再替换应用。
2. 确认下载完整；需要时可使用包内 SHA256SUMS.txt 核对文件。
3. 不要删除笔记数据目录。更换应用文件不需要清理笔记数据。
4. 若仍出现“已损坏”，请反馈完整提示、下载渠道、软件版本、macOS 版本和芯片型号。

如果系统明确提示“将损坏你的电脑”或已检测到恶意软件，请停止打开并反馈，不要按本说明强行放行。

五、版本与下载说明

• 目前提供 macOS 13 及以上、Apple Silicon（M1 / M2 / M3 / M4 / M5 等）版本。
• 本安装包不适用于 Intel Mac、Windows、iPhone 或安卓手机。
• 当前未获得 Apple 公证，不能保证所有设备都能通过上述方式打开。
• 面向普通用户免除这类首次打开拦截，需要后续完成 Developer ID 签名及 Apple 公证。
• SHA-256 校验只能帮助检查文件完整性，不能替代开发者签名与公证。
