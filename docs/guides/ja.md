# 読書パートナー利用ガイド

バージョン 0.3.x に対応します。本やウェブを読み、ノートを書き、共有用カードを作成するアプリです。基本機能にアカウントや AI キーは不要です。このガイドはオフラインで読めます。

## 1. はじめに

1. デスクトップアプリでローカルファイルを開き、EPUB、PDF、TXT を選びます。ウェブ閲覧モードで URL を直接入力することもできます。
2. 本棚で本を選び、右側に新しいノートを作成してタイトルと本文を書きます。
3. ローカルへの保存完了を確認します。これはクラウドへのバックアップではありません。
4. 共有カードを作成し、文章や配色を編集して画像を出力します。
5. JSON バックアップを保存し、元の書籍ファイルは別に保管します。

公式リリースページからインストーラーをダウンロードしてください。埋め込みウェブ表示とAI設定にはデスクトップアプリが必要です。

## 2. 画面とノート一覧

- 本棚で本の選択や情報編集、検索ができます。検索対象は保存した書名とノートのタイトル・本文で、書籍全文ではありません。
- 読書とノートの境界をドラッグして幅を調整します。ダブルクリックで初期値に戻り、フォーカス後は矢印キーでも調整できます。
- 現在のノート名の横にある下向き矢印を押すと、その本の全ノートが表示されます。「4」は通常ノート、抜粋、要約の合計件数で、数字自体は一覧ボタンではありません。
- 読書と共有スタジオを切り替えても読書ページは保持されます。本の変更や手動更新ではページが変わることがあります。
- 読書の全画面表示は終了ボタンまたは Esc で戻れます。執筆集中モードは対応する復帰ボタンを使います。
- 上部の疑問符ボタンでガイドを開きます。閉じると読書を続けられます。

本の削除：左の本棚で本の横にあるゴミ箱ボタンをクリックするか、本の情報を編集する画面で「本棚から削除」を選択します。確認画面には関連するノートの件数とバックアップ操作が表示されます。確定すると、その本のノート、抜粋、要約、共有用の下書きも削除され、取り消せません。パソコン上の元のファイルやウェブサイトのアカウント内の本には影響せず、アプリ内のファイルキャッシュは保持されます。最後の1冊も削除でき、空の本棚からURLの追加やファイルを開く操作ができます。

## 3. EPUB・PDF・TXT を読む

DRM のないファイルに対応します。上限は 1 ファイル 50 MB、TXT は 10 MB です。読み込み時に書籍をアップロードしません。

- EPUB：目次、章移動、文字サイズ、テーマ、章のしおり、読書位置の保存。独自の組版を使い、出版社の CSS、フォント、固定レイアウトを完全には再現しません。
- PDF：ページ移動、拡大縮小、ページのしおり、文字層の選択。スキャン画像から文字は選択できません。OCR、PDF 手書き注釈、フォームは未対応です。
- TXT：UTF-8 または BOM 付き UTF-16。自動分割、文字サイズ、テーマ、しおりを利用できます。文字化けする場合は UTF-8 に変換して読み込み直してください。

元ファイルが見つからない場合、同一ファイルを開くと指紋で既存ノートと進捗に再関連付けできます。内容が変わると別ファイル扱いになることがあります。原本は別に保管してください。

## 4. ウェブ閲覧と抜粋

`https://weread.qq.com` などを直接入力して Enter を押すか、ショートカットを選びます。通常の検索語は百度へ送信され、認識済みの読書サービス名は直接開けます。ログインは各サイトの手順で行い、戻る・進む・更新／停止で操作します。現在のページを本棚に登録できます。

通常の新規ウィンドウリンクは読書領域で開きますが、ログイン、支払い、明示的なポップアップは別ウィンドウになる場合があります。独立ウィンドウの許可設定で通常リンクの挙動を変えられます。

一般的な文字は選択して右クリックし、読書抜粋として保存します。確認画面で本文、出典、保存先の本を確認してください。

微信読書など独自の文字選択を使うサイトでは、サイトのコピー機能を使ってから、アプリの右クリックメニューで抜粋として貼り付けます。その操作時だけクリップボードを読み取ります。右側の抜粋ボタンから手動入力することもできます。

ログイン、会員権限、サイトのマーカーはサイト側の機能です。会員・コピー・DRM 制限を解除しません。埋め込みできないサイトもあります。問題があれば通常のブラウザでも確認してください。

## 5. ノート・抜粋・自動保存

通常ノートは自分の考え、抜粋は原文と章・ページ・URL、AI 要約は別ノートとして整理した結果です。いずれも同じ本の一覧に入り、編集や共有ができます。

ローカルの抜粋は読書本文内だけを選択し、右クリックまたは抜粋ボタンを使います。確認欄には最大 20,000 文字を入力できます。エディタは見出し、太字、斜体、リスト、引用、画像、簡単なスケッチ、取り消し・やり直しに対応します。スケッチは挿絵で、手書き認識や Goodnotes 全機能ではありません。ノート画像は共有の表紙に自動反映されません。

ノートと共有原稿は自動保存です。保存中・完了・失敗を確認し、失敗したらまずバックアップを出力して再試行してください。AI 設定の保存ボタンはサービス設定だけを保存します。

ノート下部のダウンロードは Markdown 出力で、完全なバックアップではありません。ノートを削除すると共有原稿も削除されます。ごみ箱はないため必要なら先にバックアップしてください。

## 6. AI サービスの設定

AI は任意で、利用者がキーを用意しサービス提供者へ支払います。公式の管理型 AI、購読、チャージは未実装です。

1. 設定で DeepSeek、OpenAI、Claude、Gemini、Qwen、Kimi、GLM、Ollama、カスタム API から選び、設定を追加します。
2. 名前、API 種類、URL、キーを入力します。
3. モデル一覧を取得して選ぶか、提供者のモデル ID を直接入力します。URL とキーだけで必ずモデルを検出できるわけではありません。
4. 接続テストはノートを含まない短いリクエストですが、課金される場合があります。モデル取得でも指定先へ認証情報を送ります。
5. 保存して有効化し、使用中サービスの表示を確認します。切り替え時も同じ操作です。初回保存は既定サービスになります。最大 30 設定まで保存できます。

OpenAI Chat Completions、OpenAI Responses、Anthropic Messages に対応し、Gemini は OpenAI 互換 API を使用します。URL は `https://api.example.com/v1` のように必要なバージョンパスまで指定してください。`/v1` は自動追加されません。遠隔は HTTPS、ローカルは HTTP も使用でき、URL 内の認証情報・クエリ・フラグメントは使えません。

Ollama は別途インストール・起動しモデルを準備します。通常 `http://localhost:11434/v1` を使い、キーは空欄で構いません。モデル名は一覧から選ぶか手入力します。本アプリはモデルをダウンロードしません。

キーは OS で暗号化され、保存済み値は再表示しません。空欄なら保持しますが、URL や API 種類を変える際は再入力または明示的な削除が必要です。使用中設定を削除したら別の設定を有効にしてください。

## 7. AI 要約と共有文の編集

ノートを選び AI 整理から生成を開始します。入力は 10〜50,000 文字で、選択した本文・タイトル・書名だけを送信します。原書、他のノート、Cookie、画像、スケッチは送信しません。

生成画面を開いた時点の内容を使います。生成中の編集は今回の送信に追加されません。最新内容で実行するには完了後に生成画面を開き直してください。

結果を修正・確認して新規要約ノートに保存すると元ノートは残ります。共有スタジオの AI 推敲ではタイトル、本文、タグを作り、確認して共有原稿へ適用します。再生成は再リクエストとなり課金の可能性があります。引用と著者の主張を必ず確認してください。

## 8. 共有カードと同期

1. ノートを選び共有スタジオを開きます。
2. タイトル、本文、配色、任意の JPG・PNG・WebP 表紙を設定します。
3. 短い待ち時間の後プレビューが更新されます。長文は自動改ページされ、矢印で確認できます。画像は 1080 × 1440、3:4 です。
4. 現在のカード出力は 1 ページの PNG を保存します。複数ページは個別出力で、一括出力は未対応です。
5. 文章をコピーして、小紅書などへ自分で画像と文章を投稿します。自動投稿は行いません。

タイトルと本文は初期状態でノートに連動します。共有側で編集した欄は独立し、以後ノート変更で上書きされません。個別または全体の連動復帰で最新ノートへ戻せますが、独立原稿は置き換わるため必要な文章を先に保管してください。配色と表紙は保持されます。

## 9. バックアップ・復元・移行

自動保存は端末内のみです。定期的に JSON を出力し、原書も別途保管してください。JSON は復元用データであり、共有画像ではなく手編集も不要です。

書籍情報、指紋、進捗、しおり、ノート、ノート画像、共有原稿が含まれます。原書、Cookie、API キー、言語設定は含まれません。追加の暗号化はされていません。

移行手順：最新 JSON を出力 → 原書を別途コピー → 移行先の既存ノートを先にバックアップ → JSON を復元し件数を確認 → 同一原書を再度開く → サイトログインと AI・言語設定をやり直します。

復元は現在の本棚とノートを置換し、統合しません。バックアップ上限は 100 MB。原書がなくてもノートは読めますが書籍本文は復元できません。ブラウザプレビューとデスクトップは別の保存領域で、JSON でノートを移せます。

## 10. 言語・プライバシー・保存場所

簡体字、繁体字、英語、日本語、スペイン語に対応し、システム追従または手動選択が可能です。即時反映され、AI 設定とは別に保存されます。未対応言語は英語になります。既存ノートやウェブは翻訳しません。ガイド専用の言語選択はこのガイドだけを変更します。AI の出力言語はリクエスト時の UI 言語を指定しますが、実際の結果はモデル次第です。

標準のクラウド同期、テレメトリ、広告 SDK はありません。ノートは暗号化保管庫ではありません。アプリやサイトのデータを不用意に削除しないでください。

保存先は通常、macOS `~/Library/Application Support/reading-companion`、Windows `%APPDATA%/reading-companion`、Linux `$XDG_CONFIG_HOME/reading-companion` または `~/.config/reading-companion` です。調査前に終了とバックアップを行い、使用中データを手編集しないでください。詳しくは公開ページのプライバシー・セキュリティ文書をご覧ください。

## 11. 困ったとき

- ノート一覧が見つからない：本を選び、現在のノートタイトル横のメニューを開きます。
- 抜粋が空：本文内を選択します。独自のウェブ選択はコピー後に貼り付け、スキャン PDF は外部 OCR が必要です。
- 共有に反映されない：独立編集になっていないか確認し、必要なら連動に戻して描画を待ちます。表紙は別に追加します。
- 言語が違う：手動設定を確認します。ウェブや OS ダイアログの言語は別管理です。
- AI 401/403：キーと利用権限、404：URL・パス・API 種類・モデル ID、429：残高と頻度、タイムアウト：ネットワークとサービス状態を確認します。
- モデル一覧が取得できない：ID を手入力して接続テストします。一覧未対応でも生成できる場合があります。
- 安全な保存が利用できない：OS のキーチェーン等を確認してください。Linux の平文バックエンドにはキーを保存しません。
- 更新が遅い／ログイン画面に戻る：ネットワーク、サイト、セッションを確認します。共有への切り替えで読書が更新される場合は再現手順を報告してください。
- 保存や読み込みが失敗：元データを保持し、出力できる内容をバックアップするか既存バックアップから復元します。データディレクトリの削除で試さないでください。

## 12. 制限と報告

OCR、手書き認識、PDF 注釈、書籍全文検索、クラウド同期、自動投稿、公式 AI は未対応です。Goodnotes の完全な代替ではありません。Windows/Linux GUI、すべてのサイトとモデルは未検証で、翻訳も母語話者の確認が必要です。

報告にはバージョン、OS とアーキテクチャ、言語、デスクトップ／プレビュー、再現手順、期待結果と実際の結果、個人情報のない画像を添えてください。自作の小さなファイルを使い、キー、Cookie、書籍や全ノートを公開しないでください。

通常の不具合は https://github.com/xululu0401/reading-companion/issues に報告してください。安全性の問題は公開リポジトリの SECURITY.md に従い、非公開の窓口を利用してください。
