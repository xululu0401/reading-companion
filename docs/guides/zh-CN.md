# 阅读搭子使用指南

适用于 0.3.x 免费测试版及当前未发布改进。阅读搭子把本地文件或网页阅读、笔记和图文分享放在同一工作台。基础使用不需要账号或 AI 密钥。本指南可离线阅读；界面入口与文字随语言变化。

## 1. 第一次使用

1. 启动桌面应用，点击左侧“打开本地文件”，导入 EPUB、PDF 或 TXT；也可以在阅读区切换“浏览器阅读”，直接输入网址。
2. 选中左侧书架中的书，在右侧点击“新增笔记”，输入标题和正文。
3. 等待右上角显示“已保存到本机”。这代表本机保存成功，不代表已经备份到云端。
4. 点击“制作分享卡片”，调整文案与配色，导出图片并复制文案。
5. 点击左下方“备份”，把 JSON 文件保存到你自己管理的目录，并另外保留原书文件。

请从官方发布页下载安装包。当前是早期测试版；内嵌网页和 AI 配置需要桌面应用。

## 2. 认识界面与笔记列表

- 左侧书架：选择书籍、搜索书名或笔记内容、编辑书籍信息、打开文件和添加阅读入口。搜索的是已保存的书名和笔记，不是原书全文。
- 中间阅读区：在“本地阅读”和“浏览器阅读”间切换。拖动阅读区与笔记区之间的分隔线调整宽度，双击分隔线恢复默认比例；分隔线获得焦点后可用方向键微调。
- 右侧笔记区：标题下方带向下箭头的笔记选择框可以展开当前书籍的全部笔记。书架上的“笔记数量：4”表示这本书共有四篇笔记，包含普通笔记、摘录和总结；数字本身不是列表入口。
- 顶部“阅读与笔记 / 分享工作室”切换工作模式；阅读页在切换分享时保持加载。切换书籍或主动刷新网页可能改变页面，请先确认阅读位置。
- 阅读区右上角“全屏阅读”放大阅读区；点击“退出全屏阅读”或按 Esc 返回。笔记区“专注写作”扩大写作空间，用对应的恢复按钮返回。
- 顶栏问号按钮“使用说明”打开本指南。帮助只覆盖在工作台上，关闭后可继续阅读。

删除书籍：点击左侧书籍旁的垃圾桶按钮，或进入“编辑书籍信息”后点击“从书架删除”。确认窗口会显示关联笔记数量，并提供备份入口；确认后将同时删除该书的笔记、摘录、总结及分享稿，无法撤销。删除只影响本应用书架，不会删除电脑上的原始文件或网站账号中的书籍；应用内的原书缓存仍保留。最后一本也可以删除，空书架可重新添加网址或打开文件。

## 3. 本地阅读：EPUB、PDF、TXT

点击“打开本地文件”并选择文件。支持不含 DRM 的 EPUB、PDF、TXT；单文件最大 50 MB，TXT 最大 10 MB。文件保存到本机，导入不会上传原书。

- EPUB：打开“阅读目录与书签”选择章节，使用上一节/下一节按钮翻页。可调整字号、纸张/明亮/夜间主题，添加章节书签并恢复阅读位置。采用统一排版，不保证原出版社 CSS、字体和固定版式还原。
- PDF：可跳到指定页码、缩放、添加页码书签，选择有文字层的文字。扫描图片页无法直接摘录文字；目前没有 OCR、PDF 手写批注或交互表单。
- TXT：支持 UTF-8 和带 BOM 的 UTF-16，自动分节，支持字号、主题、目录和书签。乱码时请先把文件另存为 UTF-8 再导入。

如果提示原文件缺失，重新打开完全相同的文件可按文件指纹关联已有书籍、笔记和进度。内容或文件字节改变可能被识别为另一份文件。重新导入不能代替保留原书备份。

## 4. 浏览器阅读与网页摘录

1. 切换“浏览器阅读”，在地址栏输入 `https://weread.qq.com` 等网址并回车，也可使用常用阅读入口。无需先去搜索引擎查找网址。
2. 普通关键词会提交到百度搜索；已识别的阅读入口名称可直接打开对应网站。
3. 按网站自身流程登录。前进、后退、刷新/停止用于浏览导航；保存入口按钮可把当前页面加入书架。
4. 普通新窗口链接默认在左侧打开。登录、支付或明确要求弹窗的流程可能保留独立窗口；“允许独立窗口”可调整普通网页的弹窗行为。

标准网页文字：选中文字，右键选择“保存为阅读摘录”，在确认窗口核对文字、来源与目标书籍，再保存。

微信读书等网站可能自己绘制文字和划线工具条，应用无法直接获取标准文字选区。请先使用网页工具条的“复制”，再右键“粘贴为阅读摘录”。剪贴板只在你点击该菜单时读取；保存前检查是否还是刚才复制的内容。也可点右侧“摘录”，手动粘贴并填写来源。

网站登录、付费内容及原生划线功能由网站提供。应用不解除会员、复制或 DRM 限制，也不保证所有网站都允许嵌入。网页无法打开时可先在普通浏览器检查网络、账号权限和网站状态。

## 5. 摘录、笔记与自动保存

普通笔记用于自己的理解与思考；摘录用于保留原文及文件章节、PDF 页码或网页链接；AI 总结是另存的一篇整理结果。它们都属于当前书籍的笔记，可以继续编辑和制作分享卡片。

本地摘录：在阅读正文选中文字，右键“保存为阅读摘录”，或点击“摘录选中文字”。仅选择阅读正文，不要跨到右侧编辑区。摘录确认窗口也支持手动粘贴，最多 20,000 个字符。

富文本工具栏支持标题、加粗、斜体、列表、引用、图片、简单手绘、撤销和重做。手绘以插图使用，不支持 Goodnotes 式完整手写笔记、手写识别或笔迹搜索。笔记图片不会自动成为分享封面。

笔记与分享稿会自动保存，不需要额外的“保存笔记”按钮。观察右上角“保存中 / 已保存到本机 / 保存失败”。保存失败时先“立即导出备份”，再尝试“重试保存”；不要直接清理应用数据。AI 设置里的“保存配置”只保存服务配置，不保存笔记。

当前笔记底部下载按钮导出 Markdown，适合文本整理和迁移，不等于完整备份。删除笔记也会删除它的分享稿，当前没有回收站；需要保留时先备份。

## 6. 配置 AI 服务

AI 可选，不影响基础阅读和笔记。目前是自带密钥模式，费用由所选服务商收取；官方托管 AI、账号订阅和充值尚未提供。

1. 打开“设置与 AI 服务”，选择服务商预设，再点击“添加配置”。支持 DeepSeek、OpenAI、Claude、Gemini、Qwen、Kimi、GLM、Ollama 和自定义 API。
2. 填写服务名称、接口类型、API 地址和 API 密钥。服务名称可以自定义，便于区分个人、工作或本地模型配置。
3. 点击“获取模型”并选择模型；若服务不支持列表，请按服务商文档手动填写模型 ID。网址和密钥本身不能保证自动找到可用模型。
4. 点击“测试连接”检查配置。测试只发送简短提示、不包含笔记，但可能产生少量费用；获取模型也会使用密钥向所填地址认证。
5. 点击“保存并启用”，确认上方“当前服务”显示该配置。以后切换时，选中对应配置并“保存并启用”。“保存配置”主要用于保存编辑；第一次保存配置会成为默认服务。

支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages。Gemini 预设使用其 OpenAI 兼容入口，不是原生 Gemini 接口。自定义服务要选择实际支持的协议；地址需包含服务商要求的版本路径，例如 `https://api.example.com/v1`，不会自动补出 `/v1`。远程地址要求 HTTPS，本机服务允许 HTTP；地址不能带账号密码、查询参数或锚点。

本机 Ollama：先安装并启动 Ollama，再准备可用模型；选择预设，通常使用 `http://localhost:11434/v1`，密钥可留空，获取模型或填写已安装的模型名。应用不会自动安装或下载模型。

已保存的密钥显示为“已安全保存，留空保持原密钥”，不会显示真实值。修改地址或接口类型后，需要重新输入密钥或勾选移除原密钥，避免把旧密钥发送到新目标。删除正在使用的配置后需要重新启用另一套配置。最多保存 30 套配置。

## 7. AI 总结与分享润色

先选中需要整理的一篇笔记。点击笔记区的 AI 整理入口，再“开始生成”。单次需要至少 10 个字，最多 50,000 个字符。

生成只发送本次选定笔记的文字、标题和书名，不包含整本书、全部笔记、网页登录信息、图片或手绘。应用打开生成窗口时会保存当时笔记的快照；生成中继续编辑的内容不会自动追加到这次请求。需要整理最新内容时，待本次结束后重新打开生成入口。

总结结果可直接修改，核对后点“保存为新笔记”，原笔记保留。分享工作室的“AI 润色”生成标题、正文和标签，核对后“应用到分享稿”。点击“重新生成”会再次请求服务，可能再次计费。AI 可能犯错，尤其要检查引文和作者观点。

## 8. 分享工作室与同步规则

1. 选择一篇笔记，点击“制作分享卡片”或顶部“分享工作室”。
2. 编辑分享标题和正文，选择配色，可添加 JPG、PNG 或 WebP 封面图片。右侧预览在编辑后短暂延迟更新。
3. 长文自动分页；使用预览下方箭头查看每张卡片。图片规格为 3:4，1080 × 1440 像素。
4. 点击“导出当前卡片”保存当前页 PNG。多页需要逐页导出，目前没有一次批量导出按钮。
5. 点击“复制文案”，自行打开小红书等平台，上传图片、粘贴文案并发布。软件不会自动发布，也不会登录你的社交平台账号代发。

默认标题和正文“跟随笔记”。某个字段在分享工作室单独改写后，它会变成“独立编辑”，以后修改原笔记不会覆盖该字段。点击“标题恢复跟随笔记”“正文恢复跟随笔记”或“全部跟随笔记”即可恢复同步；恢复会用笔记当前内容替换独立稿，请先保留需要的改写。配色与封面保留。

## 9. 备份、恢复与换电脑

自动保存只是保存到这台设备。建议定期点击“备份”，将生成的 JSON 放在自己管理的外部磁盘或备份目录。JSON 是供应用恢复的结构化数据，不是分享卡片；无需手动编辑。

备份包含书籍信息、文件指纹、阅读进度、书签、笔记、笔记图片与分享稿。不包含原书文件、网站 Cookie、API 密钥或语言偏好。备份没有额外加密，分享文件前注意其中可能包含私人内容。

换电脑流程：在旧电脑导出最新 JSON → 另行复制原书 → 在新电脑启动应用 → 先备份新电脑已有笔记 → 点击“恢复”选择 JSON → 核对书籍和笔记数量 → 确认恢复 → 重新打开相同原书文件 → 重新登录网站、配置 AI 与语言。

恢复会替换当前书架及笔记，不会把两份库合并。备份文件上限 100 MB。没有原书时，已恢复的笔记仍可使用，但无法恢复本地原书正文。浏览器预览和桌面版的数据分别保存，不会自动互通；可通过 JSON 迁移笔记。

## 10. 语言、隐私与本机数据

“设置与 AI 服务 → 界面语言”支持简体、繁体、英语、日语、西班牙语，可跟随系统或手动选择。切换立即生效并单独保存，不需要点 AI 的保存按钮；不支持的系统语言回退英语。已有笔记、书名与网页不会自动翻译。

本指南随界面语言显示，可用指南中的语言下拉框单独切换阅读语言。文档随应用打包，不会访问在线翻译服务。AI 按发起请求时的界面语言生成，实际输出取决于模型。

应用没有默认云同步、遥测或广告 SDK。本地文件、笔记、浏览器会话和 AI 设置是不同数据。笔记不是加密保险箱；有系统用户目录访问权的人可能读到数据。不要随意清理应用数据或浏览器站点存储。

桌面数据默认位于 Electron 的 `reading-companion` 用户数据目录：macOS 为 `~/Library/Application Support/reading-companion`，Windows 通常为 `%APPDATA%/reading-companion`，Linux 通常为 `$XDG_CONFIG_HOME/reading-companion` 或 `~/.config/reading-companion`。排查前先退出应用并备份，不要手工修改正在使用的数据文件。完整政策见公开发布页的隐私与安全说明。

## 11. 常见问题与排查

- 笔记数量是 4，如何查看？选中对应书籍，点右侧当前笔记标题旁的向下箭头；列表包含这本书的全部笔记。
- 右键没有摘录或选中文字为空？确认选区在正文内。网页自定义划选用网页“复制”后“粘贴为阅读摘录”；扫描 PDF 需要先用其他工具识别文字。
- 分享预览没跟着笔记变化？检查该字段是否为“独立编辑”，需要同步时恢复跟随；排版中稍等片刻。分享封面需单独添加。
- 系统是中文却显示英文？检查界面语言是否手动设为 English；选择简体中文或跟随系统。网页内容和操作系统对话框不由应用翻译。
- API 报 401/403？检查密钥、账户权限及该模型授权。404 通常检查地址、版本路径、协议或模型 ID；429 检查额度与频率。连接超时则检查服务状态与网络，不要重复快速点击。
- 获取不到模型，但服务可用？手动填写服务商提供的模型 ID，再测试连接；不支持模型列表不代表无法生成。
- 提示系统安全存储不可用？应用会拒绝保存密钥。检查系统钥匙串或凭据服务；Linux 不支持用明文后端保存密钥。
- 网页刷新慢或回到登录页？刷新会重新请求网站；检查网络、网站状态与登录会话。分享模式切换不应主动刷新阅读页；若仍发生，请记录步骤和脱敏后的网址反馈。
- 保存失败或启动无法读取？保留原数据文件，优先导出当前备份或恢复已有备份。不要删除整个数据目录试错。

## 12. 当前限制与问题反馈

当前是早期测试版。尚未提供 OCR、手写识别、PDF 批注、原书全文搜索、云同步、自动发布社交平台、官方付费 AI 或完整 Goodnotes 能力。Windows/Linux GUI、全部网站和所有模型并未完成实测；翻译尚需母语校对。Mac 测试构建未正式签名或公证。

反馈时请提供：应用版本、操作系统及架构、界面语言、桌面版或浏览器预览、最短复现步骤、预期与实际结果，以及不含私人内容的截图。尽量用原创小文件复现，不要上传原书、Cookie、真实 API 密钥或完整笔记库。

普通问题可在 https://github.com/xululu0401/reading-companion/issues 反馈。安全问题按公开仓库的 SECURITY.md 使用私密渠道，不公开敏感细节。
