# 閱讀搭子使用指南

適用於 0.3.x 免費測試版及目前尚未發布的改進。在同一工作台閱讀本機書籍或網頁、記錄筆記並製作分享卡片。基本使用不需要帳號或 AI 金鑰，本指南可離線閱讀。

## 1. 第一次使用

1. 啟動桌面版，點選「開啟本機檔案」匯入 EPUB、PDF 或 TXT，或切換至瀏覽器閱讀並輸入網址。
2. 在書架選擇書籍，於右側新增筆記，填寫標題和想法。
3. 等待顯示已儲存至本機；這不代表已備份至雲端。
4. 製作分享卡片，編輯文字與配色，匯出圖片並複製文案。
5. 匯出 JSON 備份，另外保留原書檔案。

請從官方發佈頁下載安裝包。目前是早期測試版；內嵌網頁和 AI 設定需要桌面應用程式。

## 2. 介面與全部筆記

- 書架可選擇書籍、編輯資訊、搜尋書名與筆記；搜尋不涵蓋原書全文。
- 拖曳閱讀與筆記之間的分隔線調整寬度，連按兩下還原；分隔線取得焦點後可用方向鍵微調。
- 點選目前筆記標題旁的向下箭頭，展開這本書的全部筆記。「筆記數量：4」包含普通筆記、摘錄及摘要，數字本身不是清單入口。
- 閱讀與分享工作室切換時保留閱讀頁面；切換書籍或主動重新整理可能改變頁面。
- 全螢幕閱讀可用退出按鈕或 Esc 返回；專注寫作可用對應的還原按鈕返回。
- 頂端問號按鈕開啟本指南，關閉後繼續閱讀。

刪除書籍：點擊左側書籍旁的垃圾桶按鈕，或進入「編輯書籍資訊」後點擊「從書架刪除」。確認視窗會顯示關聯筆記數量，並提供備份入口；確認後會一併刪除該書的筆記、摘錄、摘要及分享稿，無法復原。只影響本應用程式書架，不會刪除電腦上的原始檔案或網站帳號中的書籍；應用程式內的原書快取仍保留。最後一本也可以刪除，空書架可重新新增網址或開啟檔案。

## 3. 本機 EPUB、PDF、TXT

支援不含 DRM 的檔案，單檔上限 50 MB，TXT 上限 10 MB。匯入不會上傳原書。

- EPUB：目錄、上一章／下一章、字級、主題、章節書籤與閱讀位置。採統一排版，不完整還原出版社樣式、字型或固定版面。
- PDF：頁碼跳轉、縮放、頁碼書籤與文字選取。掃描圖片頁無法直接選字，目前沒有 OCR、手寫批註或互動表單。
- TXT：支援 UTF-8 或含 BOM 的 UTF-16，自動分節，提供字級、主題和書籤。亂碼時請先另存為 UTF-8。

原檔遺失時，重新開啟完全相同的檔案可依指紋關聯筆記與進度；檔案內容改變可能被視為另一份書籍。請另外備份原書。

## 4. 瀏覽器閱讀與網頁摘錄

直接輸入 `https://weread.qq.com` 等網址並按 Enter，或使用常用入口。普通關鍵字會提交至百度搜尋；已辨識的閱讀服務名稱可直達網站。依網站流程登入，使用上一頁、下一頁、重新整理／停止導航，並將目前頁面儲存至書架。

普通新視窗連結預設於閱讀區開啟；登入、付款或明確要求彈出視窗的流程可能另開視窗。「允許獨立視窗」可調整普通連結的行為。

標準文字選區：選字後按右鍵儲存為閱讀摘錄，確認文字、來源與目標書籍再儲存。

微信讀書等網站可能採用自訂選區。先點網站工具列的複製，再按右鍵選擇貼上為閱讀摘錄。只有點選該功能時才讀取剪貼簿；請核對貼上的內容。也可點右側摘錄，手動貼上文字與來源。

網站會員、登入與原生畫線由網站提供。應用不解除會員、複製或 DRM 限制，也不保證所有網站可嵌入；無法開啟時先在普通瀏覽器檢查網站與帳號狀態。

## 5. 摘錄、筆記與自動儲存

筆記記錄自己的理解；摘錄保留原文與章節、頁碼或網址；AI 摘要是另存的一篇筆記。三種內容都在該書的筆記清單中，可以編輯與分享。

本機文字須完整選在閱讀正文內，再用右鍵或頂端摘錄按鈕。確認視窗可手動貼上，最多 20,000 個字元。編輯器支援標題、粗體、斜體、清單、引言、圖片、簡單手繪、復原與重做。手繪是插圖，不提供完整 Goodnotes 功能或手寫辨識；筆記圖片不會自動變成分享封面。

筆記與分享稿自動儲存。注意儲存中、成功或失敗的狀態；失敗時先匯出備份，再重試，不要清除應用資料。AI 設定的儲存按鈕只處理服務設定。

筆記底部下載按鈕匯出 Markdown，供文字整理使用，不是完整備份。刪除筆記也會刪除分享稿，目前沒有資源回收筒，需要保留時先備份。

## 6. 設定 AI 服務

AI 為選用功能，使用自己的金鑰並向服務商付費。官方託管 AI、帳號訂閱與儲值尚未提供。

1. 在設定中選擇服務商預設並新增設定。提供 DeepSeek、OpenAI、Claude、Gemini、Qwen、Kimi、GLM、Ollama 與自訂 API。
2. 填寫名稱、介面類型、API 網址與金鑰。
3. 取得模型後選擇，或依服務商文件手動填寫模型 ID。網址和金鑰不保證自動找到可用模型。
4. 測試連線只送出簡短提示、不含筆記，但可能計費；取得模型也會向所填網址傳送認證。
5. 儲存並啟用，核對目前服務。切換其他設定時同樣儲存並啟用；首次儲存的設定會成為預設，最多可儲存 30 套。

支援 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages。Gemini 使用 OpenAI 相容介面。網址須包含必要的版本路徑，例如 `https://api.example.com/v1`；不會自動補上 `/v1`。遠端要求 HTTPS，本機可用 HTTP，不接受網址內的帳密、查詢參數或錨點。

Ollama 須先自行安裝、啟動並準備模型；通常使用 `http://localhost:11434/v1`，金鑰可空白，再取得模型或輸入已安裝的模型名。應用不會下載模型。

已儲存的金鑰由作業系統加密，不回顯原值；留白可保留。修改網址或介面類型時須重新輸入或明確移除舊金鑰。刪除正在使用的設定後，須重新啟用另一套。

## 7. AI 摘要與分享潤飾

選擇一篇筆記，開啟 AI 整理再開始生成。文字至少 10 個字，最多 50,000 個字元。只傳送所選筆記文字、標題和書名，不傳送原書、其他筆記、Cookie、圖片或手繪。

生成視窗使用開啟當時的筆記快照，生成中繼續編輯不會加入該次請求；要使用最新內容，待本次結束後重新開啟生成入口。

結果可修改並另存為摘要筆記，原筆記保留。分享工作室的 AI 潤飾產生標題、正文和標籤，確認後套用至分享稿。重新生成會再次請求並可能計費；請核對引文與作者觀點。

## 8. 分享卡片與同步

1. 選擇筆記，進入分享工作室。
2. 編輯標題、正文、配色，可另外加入 JPG、PNG 或 WebP 封面。
3. 預覽稍候更新；長文自動分頁，用箭頭切換，圖片為 1080 × 1440、3:4。
4. 匯出目前卡片只儲存一張 PNG，多頁須逐頁匯出，尚無批次匯出。
5. 複製文案後自行前往小紅書等平台上傳發布，軟體不會自動代發。

標題與正文預設跟隨筆記，單獨編輯某欄位後會保留獨立稿。可分別或全部恢復跟隨；這會用目前筆記覆蓋獨立文字，請先保留需要的改寫。配色和封面會保留。

## 9. 備份、還原與換電腦

自動儲存只在本機。定期匯出 JSON 並另外保留原書。JSON 是還原資料，不是分享圖片，無須手動編輯。

備份包含書籍資訊、檔案指紋、進度、書籤、筆記、筆記圖片和分享稿；不含原書、Cookie、API 金鑰與語言偏好。備份沒有額外加密。

換電腦：匯出最新 JSON → 另行複製原書 → 新電腦先備份現有筆記 → 選擇還原並核對數量 → 確認 → 開啟相同原書 → 重新登入網站並設定 AI 和語言。

還原會替換目前書架與筆記，不會合併；備份上限 100 MB。沒有原書仍能閱讀已還原筆記，但無法還原書籍正文。瀏覽器預覽與桌面版各自儲存，可用 JSON 遷移筆記。

## 10. 語言、隱私與資料

介面支援簡體、繁體、英語、日語、西班牙語，預設跟隨系統，也可手動選擇，立即生效且獨立儲存；不支援的系統語言回退英語。既有筆記、書名及網頁不會自動翻譯。本指南另有語言選單，只切換指南，不改介面。AI 使用請求當時的介面語言，實際輸出依模型而定。

沒有預設雲同步、遙測或廣告 SDK；本機筆記不是加密保險箱。不要任意清理應用或瀏覽器網站資料。

桌面資料通常位於 macOS 的 `~/Library/Application Support/reading-companion`、Windows 的 `%APPDATA%/reading-companion`、Linux 的 `$XDG_CONFIG_HOME/reading-companion` 或 `~/.config/reading-companion`。排查前退出並備份，不要手動修改使用中的資料。詳細政策見公開發布頁的隱私與安全文件。

## 11. 常見問題

- 找不到全部筆記：選書後展開目前筆記標題旁的下拉清單。
- 摘錄為空：確認選區在正文；網頁自訂選區先複製再貼上；掃描 PDF 需其他 OCR 工具。
- 分享未同步：檢查是否獨立編輯，必要時恢復跟隨並等待排版；封面需另加。
- 語言不正確：檢查是否有手動覆寫。網頁和作業系統對話框使用自己的語言。
- AI 401/403：檢查金鑰及模型權限；404：檢查網址、版本路徑、協定和模型 ID；429：檢查額度或頻率；逾時：檢查網路和服務狀態。
- 模型清單不支援：手動輸入模型 ID 再測試，不代表無法生成。
- 安全儲存不可用：檢查系統鑰匙圈或憑證服務，Linux 不允許用明文後端儲存金鑰。
- 重新整理很慢或回到登入頁：檢查網站、網路及登入狀態；切換分享不應主動重新整理閱讀頁，若可重現請回報。
- 儲存或載入失敗：保留原資料，先備份或從已知備份還原，不要直接刪除資料目錄。

## 12. 限制與回報

目前未提供 OCR、手寫辨識、PDF 批註、原書全文搜尋、雲同步、自動社交發布或官方託管 AI，也不具備完整 Goodnotes 能力。Windows/Linux 介面、所有網站及模型尚未全面實測，翻譯仍待母語校對。

回報請附版本、系統與架構、語言、桌面或預覽模式、最短步驟、預期與實際結果，以及不含私人資料的截圖。使用原創小檔案重現，不附真實金鑰、Cookie、原書或整套筆記。

一般問題可在 https://github.com/xululu0401/reading-companion/issues 回報。安全問題依公開倉庫的 SECURITY.md 私下處理，不公開敏感細節。
