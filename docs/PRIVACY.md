# 隐私与数据

本文件描述 0.3.x 免费测试版，不代表未来在线服务的政策。

- 界面翻译随应用打包，不调用翻译服务。语言偏好在桌面端 language.json 或浏览器 localStorage 中保存，不包含在笔记备份里。AI 请求会附带所选输出语言。
- 无账号系统、遥测、广告 SDK 或默认云同步。
- 笔记、图片、分享稿和阅读进度保存在本机。桌面 workspace.json 位于 Electron userData 目录；本地原书保存在应用页面的 IndexedDB（reading-companion-files）。开发网页与桌面文件页面的存储互相独立。
- 浏览器登录 Cookie 保存在隔离的持久会话。访问网站会直接连接该网站，适用网站自身的隐私条款。为兼容旧版本，内部会话名仍保留 persist:weread，此名称不限制访问网站。
- 地址栏提交普通关键词时，会将关键词发送给百度搜索；输入网址或已知阅读入口名称时直接访问对应网站。未提交的输入不会发送。
- 打开本地 EPUB、PDF、TXT 不会将文件上传。EPUB 外部图片、样式、脚本不加载。PDF 字体、字符映射和 worker 随应用本地提供。
- AI 不是自动上传：点击“开始生成”或“重新生成”才会将当时选定的笔记文字、标题和书名发送到设置中的 AI 地址。原书、Cookie、其他笔记、手绘和笔记图片不发送。用户应按服务商政策判断保存期限与使用方式。
- API 密钥输入表单后交由主进程使用系统能力加密保存；已保存的密钥不回传应用页面、不进入 JSON 备份。不同服务配置独立保存，修改目标地址或接口类型不会静默复用原密钥。模型费用由服务商收取。
- 点击“获取模型”会使用当前配置的密钥请求服务的模型列表；点击“测试连接”会发送简短测试提示，可能计费。这两类请求不包含笔记。只在点击生成时发送选定笔记到已启用服务。
- JSON 备份包含书籍元数据、文件指纹、进度、书签、笔记和分享稿；不含原书文件、网站 Cookie 或 API 密钥。换设备后重新导入完全相同的原文件，会按 SHA-256 指纹关联原有笔记。
- PNG、Markdown、文案导出由用户决定是否分享。本项目不会自动发布到社交平台。

清理浏览器站点数据或删除应用 userData 目录会删除本地数据，请先导出笔记并自行保留原书。应用不提供数据恢复服务。公开提交问题前，请删除截图和日志中的个人内容。
