# 安全问题 / Security reports

优先使用仓库 Security → Advisories → Report a vulnerability 私密报告安全问题。如该入口不可用，请仅提交“请求私密联系方式”的 Issue，不包含漏洞细节。请勿公开 API 密钥、Cookie、私人笔记或受版权限制的书籍。

Use GitHub private vulnerability reporting if available. Otherwise request a private contact through an issue without disclosing exploit details or private data. This preview has not undergone an independent security audit.
